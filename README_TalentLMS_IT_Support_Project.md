# Competency-Based IT Support Learning Programme

## Project Overview

This is an independent Learning & Development portfolio project designed and administered in **TalentLMS**.

The project demonstrates how a competency-based, on-the-job training programme can be structured for an **entry-level IT Support Technician**. The course focuses on practical workplace capability. Learners progress through structured learning units, scenario-based activities and instructor-reviewed practical assessments before competency sign-off.

> **Note:** This is an independent portfolio project and is not an official training programme of any employer or organisation.

---

## Intended Audience

The programme is designed for:

- Entry-level IT Support Technicians
- New starters requiring foundational IT support training
- Learners developing structured troubleshooting, security-awareness and escalation skills

---

## Learning Objectives

By the end of the programme, learners should be able to:

- Identify and respond to common user-account and access issues
- Apply a structured approach to basic network troubleshooting
- Recognise indicators of a potential cybersecurity incident
- Gather and record relevant information before taking action
- Decide when an issue should be resolved at first-line support or escalated
- Document technical incidents clearly for the next support level

---

## Learning Design Approach

The course was designed using a competency-based approach.

Each competency follows a consistent learning sequence:

**Competency → Learning Content → Scenario-Based Practice → Practical Assessment**

The programme includes:

- Competency requirements
- Sequential course progression
- Learning units that focuses on tasks
- Activities based on scenarios
- Assignments reviewed by Instructors
- Competency sign-off criteria
- Learner enrolment and progress tracking
- Reporting of the status of the Course and Training 

The practical assessments are designed to evaluate whether a learner can **apply** the required process, rather than only recall information.

---

## Course Structure

### 1. Course Overview
Introduces the purpose of the programme, intended audience, expected outcomes and completion requirements.

### 2. Competency Requirements
Explains the four core competencies learners are expected to demonstrate.

### 3. User Account Support
Covers common user-access issues, initial account checks, troubleshooting decisions and escalation.

**Units include:**
- Competency
- Initial User Account Support
- User Account Support Scenario
- Practical Assessment

### 4. Basic Network Troubleshooting
Introduces a structured approach to identifying and troubleshooting common connectivity issues.

**Topics include:**
- Identifying the scope of a connectivity problem
- Wi-Fi and Ethernet checks
- IP configuration
- Connectivity testing
- DNS and browser/application checks
- Documentation and escalation

### 5. Security Incident Identification
Develops the learner's ability to recognise potential security incidents and collect the information required for escalation.

**Topics include:**
- Suspicious emails and links
- Unexpected pop-ups and system behaviour
- Credential requests
- Information gathering
- Preserving relevant details
- Security escalation

### 6. Documentation & Escalation
Focuses on creating clear support records that allow another technician to continue an investigation without repeating completed work.

**Topics include:**
- Problem description
- Scope and affected users
- Troubleshooting steps performed
- Results and findings
- Actions taken
- Reason for escalation

### 7. Final Practical Assessment
Brings multiple competencies together in a realistic IT-support scenario.

Learners are required to identify the issue, perform appropriate initial checks, recognise possible security concerns, document their findings and decide whether escalation is required.

### 8. Completion & Competency Sign-Off
Defines the conditions for successful course completion and instructor-reviewed competency sign-off.

## Example Scenario-Based Assessment

One assessment presents a learner with an unexpected online meeting invitation that appears to be a Microsoft Teams link but directs to an unfamiliar web address.

The learner must:

- Identify the warning signs
- Decide whether the situation should be treated as a potential security incident
- Explain what information should be collected
- Recommend appropriate immediate actions
- Decide whether escalation is required
- Produce a clear support/security incident record

The assessment is completed through an **instructor-reviewed TalentLMS assignment**.

## Learner Testing & Usability Review

The course is tested from both the **administrator/instructor** and **learner** perspectives.

Test learner accounts are used to review:

- Course navigation
- Sequential progression
- Clarity of instructions
- Assignment submission
- Instructor grading
- Completion status
- Learner progress reporting

A second learner is used with partial completion so that reporting can demonstrate the difference between **not started, in progress and completed** training.

## Reporting

The project includes practice with TalentLMS reporting features to review learner progress.

- Course-level learner progress
- Unit-level completion
- Assignment status
- Training status across learners

## What I Learned

This project helped me understand that an LMS is more than a platform for uploading learning content.

I gained practical experience in:

- Translating workplace tasks into measurable competencies

- Designing scenario-based activities that reflect realistic workplace situations
